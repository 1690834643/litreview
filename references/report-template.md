# report-template.md — 综述 docx 结构与文献表

综述写成 Markdown（中文正文 + 英文术语），再用 `build_docx.py` 转期刊标准字体 Word。
**主题化叙述**，不是逐篇罗列摘要。

## 建议章节
```markdown
# <综述标题>

## 摘要
3-5 句：研究背景缺口 + 本综述覆盖范围 + 核心结论。

## 1 引言
领域背景、为什么重要、综述的问题边界与组织方式。

## 2 <主题轴一>
按机制/主题展开，整合多篇证据；句末标注引用（作者 年）。

## 3 <主题轴二>
...（按 intake 的范围拆 2-4 个主题轴）

## 4 方法学/证据强度比较
不同研究的数据类型、物种范围、因果证据强弱横向比较。

## 5 研究空白与展望（gap analysis）
显式指出尚未解决的问题、矛盾结论、方法局限、值得做的方向。

## 6 高水平论文范围
按中科院分区分级，列本主题的代表性高区/TOP 工作及其贡献（数据来自 easyScholar）。

## 7 文献对比表
见下。

## 参考文献
统一格式（建议：作者. 年. 题. 期刊, 卷:页. DOI）。
```

## 文献对比表（核心，每篇标 IF/分区）
Markdown 表格（pandoc 会渲成 Word 表）。列定义：

| 列 | 内容 |
|----|------|
| 序号 | 1,2,... |
| 文献 | 第一作者 + 年 |
| 期刊 | 期刊全称 |
| 中科院分区 | `sciUp`（+`·TOP` 若 `sciUpTop`） |
| JCR / IF | `sci` / `sciif` |
| 物种/对象 | 研究的物种或体系 |
| 方法 | 关键方法（RNAi/CRISPR/比较基因组…） |
| 核心发现 | 一句话 |
| 与主题关系 | 对本综述论点的作用 |

示例：
```markdown
| # | 文献 | 期刊 | 中科院分区 | JCR/IF | 物种 | 方法 | 核心发现 | 与主题关系 |
|---|------|------|-----------|--------|------|------|---------|-----------|
| 1 | Author 2020 | Insect Science | 农林科学1区·TOP | Q1/3.0 | *Chilo suppressalis* | RNAi | *Masc* 控雄性化 | 性别决定主开关 |
```

## 字体（build_docx.py 已内置，Word 打开即正确）
- 正文：西文 Times New Roman 12pt + 中文 宋体，行距 1.5，两端对齐
- 标题：西文 Times New Roman 加粗 + 中文 黑体（H1 16 / H2 14 / H3 13）
- 文档标题 Title：18pt（传 `--title` 时生成封面标题）
- 表格 / 紧凑段：Times New Roman + 宋体 10.5pt（五号）
- 正文前自动插入两级目录（TOC，pandoc `--toc --toc-depth=2`）

## 写作约束
- 围绕「要解决的问题」组织：开头点题、结尾回应；不要逐篇摘要罗列。
- 主题化整合（3-5 轴），每篇精读文献正文有实质讨论（贡献+方法+局限），不只在文献表。
- **正文 ≥ min_words 字**（默认 8000，不含文献表/参考文献）；写深不灌水。
- 不编造数据/结论/引用；证据不足明说有争议。

## 校对清单
- [ ] 正文字数达标（≥ min_words）

- [ ] 每篇精读文献正文有实质讨论（不只在表里）
- [ ] 物种名、基因名斜体（*Bombyx mori*, *Masc*, *Znf-2*）
- [ ] IF/分区数字与 `ranks.json` 一致，未编造
- [ ] 每个论断有引用支撑
- [ ] 表格列对齐、无溢出
