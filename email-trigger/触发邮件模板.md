# 文献综述 · 邮件触发使用说明（发给同门照抄）

想让系统自动做一篇文献综述，**发一封邮件**到指定 QQ 邮箱即可。系统会自动检索、下载、
精读、查中科院分区，生成一篇 **Word 综述**回信给你（作邮件附件），源 PDF 则给一个**下载链接**自取。

## 怎么发

- **收件人**：`169xxxx@qq.com`（向管理员要准确地址）
- **主题**：必须以 `[综述]` 开头，后面写题目。例：`[综述] 鳞翅目性别决定的趋同演化`
- **正文**：按下面模板填。**`暗号` 和 `主题` 必填**，其余可留空（系统用默认值）。

## 正文模板（复制改写）

```
暗号: YOUR-SECRET-TOKEN
主题: 鳞翅目性别决定的趋同演化与 W 染色体周转
要解决的问题: 不同鳞翅目谱系的性别决定上游信号是否趋同起源、W 染色体如何周转
范围: Masc / Znf-2 / Fem-piRNA / dsx 剪接；昆虫为主
时间窗: 2015-2026，经典奠基文献不限年份
重点期刊分区: 1区/TOP 优先，但不漏经典
篇数: 分诊 60 篇，精读 20 篇
字数: 8000 以上
必读文献: 10.1126/science.xxxxx; 10.1038/xxxxx
回信地址: 你的邮箱@xx.com   （留空则回到发件邮箱）
备注: 侧重机制比较，少讲方法学
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 暗号 | ✅ | 防滥用口令，向管理员要；不对的邮件直接忽略 |
| 主题 | ✅ | 综述的题目/方向；缺了会回信让你补 |
| 要解决的问题 | 建议填 | 你想用这篇综述回答的核心问题；全文会围绕它组织、首尾呼应。留空则系统自行从主题提炼 |
| 范围 | | 物种/基因/机制边界，越具体越准 |
| 时间窗 | | 默认近 10 年优先 |
| 重点期刊分区 | | 默认高区/TOP 优先，不硬删低区经典 |
| 篇数 | | 默认 分诊 ~60 / 精读 ~20 |
| 字数 | | 综述正文最少字数，默认 8000；要更详细就写大些 |
| 必读文献 | | 必须纳入的 DOI，分号隔开 |
| 回信地址 | | 默认回发件人 |
| 备注 | | 其它要求 |

## 你会收到什么

回信内容：
- **附件 `*.docx`** —— 中文综述正文（英文术语保留），含**文献对比表**（每篇标 IF + 中科院分区），期刊标准字体排版
- **正文里的源 PDF 下载链接** —— 形如 `https://your-domain.com/litdl/<随机码>/sources.zip`，点开自取（约 14 天后失效）
- 正文还有：总览摘要 + 高水平论文范围 + 没拿到全文的「待补清单」（系统已在科研通发了求助）

## 注意

- 一次完成、不来回问你，所以**正文尽量写清楚**。
- 多人同时发会排队（同时最多 3 个并行）。
- 完整跑一篇可能要几十分钟到几小时（含等科研通传 PDF），耐心等回信。
